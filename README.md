## 3. SEO Discussion Questions

**1. Define SEO and explain its purpose in web development.**
SEO (Search Engine Optimization) is the practice of optimizing a website to increase its visibility and ranking on search engine results pages like Google. Its primary purpose in web development is to drive organic, targeted traffic to the site by making it easier for search engines to crawl, index, and understand the content.

**2. Explain how SEO practices can improve user experience (UX) and website performance.**
SEO encourages clean code structuring, mobile responsiveness, and fast loading speeds, which directly enhance user satisfaction. Good UX elements—such as descriptive image alt text, semantic HTML, and clear navigation—make it easier for both humans and search engines to interact with the site.

**3. Discuss the benefits of implementing SEO on a website.**
Implementing SEO increases brand awareness, builds credibility with users, and generates higher conversion rates (such as more booking requests). For a local service like Didi's Mobile Beauty Spa, it ensures potential clients searching for mobile treatments nearby can easily find the business online.

**4. Explain and demonstrate specific SEO techniques using HTML, CSS and JavaScript where applicable.**
On-page SEO techniques include using structured semantic heading tags (<h1>, <h2>) to organize content and adding descriptive alt attributes to images. Additionally, technical SEO files like robots.txt and sitemap.xml are implemented in the project root to guide web crawlers.

**5. Explain the purpose of HTML meta elements and demonstrate relevant examples.**
Meta elements provide search engines and browsers with critical metadata about a web page. For example, `<meta name="description" content="Professional mobile spa treatments delivered to your door.">` tells search engines what the page is about for search results snippets, while Open Graph tags optimize how links appear when shared on social media.
